# Upwork Portfolio Entry

## Title

API & Webhook Monitoring Dashboard with Automated Retry System

## Short description

Built a FastAPI control center that receives and validates webhook events, records complete request history, forwards payloads to external APIs, retries failed deliveries, and exports incident data to CSV and Excel.

## Key capabilities

- Dynamic webhook receiver endpoints
- JSON and shared-secret validation
- Complete headers, body, query, and response logging
- Manual replay and automated retry workflow
- API request testing console
- SQLite event history
- CSV and Excel reports
- Swagger documentation
- Responsive dashboard UI
